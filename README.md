# Restaurant-Sales-Operations-BI-Dashboard-Excel
Sales Operations BI Dashboard

Overview
This project analyzes retail sales transaction data to identify revenue trends, product performance, and operational sales insights. An interactive Excel dashboard was developed to visualize KPIs and support business decision-making.

Tools Used
Microsoft Excel
Pivot Tables
Data Cleaning
Data Visualization

Key Features
KPI dashboard tracking revenue and orders
Sales trend analysis
Product and city performance analysis
Purchase channel insights
Interactive filters

Key Insights
Identified top performing cities and products
Discovered top performing purchase mediums
